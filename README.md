# Creative-Pro · 创意生产实验室

**把模糊的想法，变成可复用的创意配方。**

Creative-Pro 是 **Creative Production Lab** 的公开项目展示仓库。
从视觉生成、UI 设计到文本创作，把预览、提示词和使用方法放在一起，让你找到方向后能接着动手。

**[打开网站 ↗](https://pprompt.online/) · [探索模板](https://pprompt.online/explore/) · [English](README.en.md)**

## 为什么做这个

保存过很多好看的截图，真正开始创作时，还是不知道从哪一句写起。

我想做一架随手可取的创意配方：先看结果，再理解做法，把有用的限制和表达带进自己的下一次创作。

## 你可以从这里开始

| 想做什么 | 从哪里开始 |
| --- | --- |
| 给图片找一个创作方向 | [视觉生成](https://pprompt.online/category/visual-generation/)：浏览预览与配方，选择合适的模板 |
| 把页面做得更有章法 | [UI 设计](https://pprompt.online/category/ui-design/)：设计规则、页面方向、组件状态 |
| 让文字更贴近任务 | [文本创作](https://pprompt.online/category/text-creation/)：品牌表达、文章流程、产品微文案 |
| 有想法，但不知道怎么起步 | [灵感诊断台](https://pprompt.online/#diagnostic)：选一个卡点，拿走限制和起手句 |

搜索用途或关键词 → 按分类、作品类型、创作特征筛选 → 打开详情 → 使用模板。

UI 和文本模板复制后，可带到你常用的工具中；带 Skill 的视觉模板会回到首页创作入口。站内生成涉及账号、积分与服务状态，以页面提示为准。
