## 四条串帖

**1 / 为什么做**

收藏了一张好海报、一种界面、一段文字之后，接下来怎么开始？
我把自己的起步方法整理成了 Creative-Pro / 创意生产实验室。

**2 / 先看方向**

从视觉、UI 或写作任务进入，按关键词、作品类型和创作特征筛选。
先看预览，找到与你这次任务有关的配方。

**3 / 再看方法**

完整提示词、使用步骤和约束放在详情里。
灵感诊断台则把“我卡住了”，变成一个具体限制和可编辑的起手句。

**4 / 带回自己的作品**

复制 UI 或写作配方，带到常用的 AI 工具中尝试。

项目：https://github.com/AurvalLab/Creative-Pro
